Compromisso

O KIRA segue o Modelo de Acessibilidade em Governo Eletrônico (eMAG) e as Diretrizes de Acessibilidade para Conteúdo Web (WCAG) 2.1, nível AA.

Atalhos de teclado

A barra no topo de cada página traz atalhos numerados. O navegador escolhe a combinação de teclas que aciona cada um.

{# RED-34: os tres atalhos e a combinacao por navegador. #}
Atalhos e a combinação em cada navegador
Atalho Leva a Chrome e Edge no Windows Firefox macOS
1 Conteúdo principal Alt + 1 Alt + Shift + 1 Control + Option + 1
2 Menu principal Alt + 2 Alt + Shift + 2 Control + Option + 2
3 Busca de inovações Alt + 3 Alt + Shift + 3 Control + Option + 3

Os atalhos 2 e 3 aparecem depois de entrar no sistema.

Se o leitor de tela ou o sistema operacional já usa a mesma combinação, o atalho dele prevalece. Nesse caso, chegue aos mesmos lugares pela tecla Tab ou pelos links da barra.

Alto contraste

O botão de alto contraste fica na barra no topo de cada página. Ligado, ele deixa o fundo preto, o texto branco, os links e o foco em amarelo e todos os links sublinhados.

A escolha vale em todas as páginas, neste navegador, até você apertar o mesmo botão de novo.

Ampliação

Use o zoom do navegador até 200%. O conteúdo se reorganiza na largura da janela, sem perda de informação.

Relatar uma barreira

Se alguma parte do sistema não funcionar para você, fale com o administrador do sistema. Diga em que página estava e o que tentou fazer.
